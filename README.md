## Date and Time Utility
## Project Description
The Date and Time Utility is a Python-based application that performs different date and time calculations using Python's built-in datetime module.
##  Objective
To learn practical date and time manipulation using Python.
## Technologies Used
- Python
- datetime module
## Features
1. Calculate age using date of birth.
2. Calculate the number of days between two dates.
3. Calculate working days excluding weekends.
4. Display formatted current date and time.
5. Validate date inputs.
6. Handle leap years using Python's datetime module.
## How to Run
1. Install Python.
2. Create a file named "date_time_utility.py".
3. Copy the Python code into the file.
4. Run the program.
5. Select an operation from the menu.
6. Enter the required date values in YYYY-MM-DD format.
